# Time Complexity Visualizer

An interactive web-based platform designed to help students and developers understand the behavior, efficiency, and complexity of algorithms through real-time visualizations and code analysis.

---

## Project Overview

Time Complexity Visualizer is an educational web application developed using **HTML, CSS, and Vanilla JavaScript**. The platform allows users to visualize how sorting and searching algorithms work step-by-step while also providing a built-in code complexity analyzer.

Traditional algorithm learning often relies on static code examples and mathematical formulas, making it difficult for beginners to understand how algorithms behave during execution. This project bridges that gap by providing dynamic visualizations, interactive controls, and complexity analysis tools.

---

##  Features

### Sorting Algorithm Visualizer

Visualize the execution of:

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort

Features include:

* Random Array Generation
* Adjustable Array Size
* Adjustable Execution Speed
* Real-Time Animations
* Step-by-Step Visualization

---

###  Searching Algorithm Visualizer

Supports:

* Linear Search
* Binary Search

Features include:

* Target Value Input
* Visual Element Comparison
* Search Result Highlighting
* Sorted Array Search for Binary Search

---

### Complexity Information Panel

Displays:

* Best Case Complexity
* Average Case Complexity
* Worst Case Complexity
* Space Complexity

For each algorithm.

---

###  Statistics Dashboard

Tracks:

* Number of Comparisons
* Number of Swaps
* Execution Time

During algorithm execution.

---

###  Code Complexity Analyzer

Users can paste code directly into the application and receive:

* Estimated Time Complexity
* Estimated Space Complexity
* Complexity Explanation

Supports detection of:

* O(1)
* O(log n)
* O(n)
* O(n²)
* O(n³)
* O(n log n)
* Recursive Algorithms
* Merge Sort Patterns
* Quick Sort Patterns
* Binary Search Patterns
